Update your /etc/hosts file to map myapp.local to 127.0.0.1 by adding this line:
127.0.0.1 myapp.local

Create an Apache virtual host configuration file at /etc/apache2/sites-available/myapp.local.conf with the following content:

<VirtualHost *:80>
    ServerName myapp.local
    DocumentRoot /home/yourusername/dev/myapp/public
    <Directory /home/yourusername/dev/myapp/public>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>

Replace yourusername with your actual Linux username.

Enable the site and reload Apache:

sudo a2ensite myapp.local.conf
sudo a2enmod rewrite
sudo systemctl reload apache2

Now, access your application via http://myapp.local in your browser.
